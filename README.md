# Furrever AI — React Website

Complete frontend React.js website for Furrever AI pet care app.

## Getting Started

```bash
npm install
npm start
```

Opens at http://localhost:3000

## Build for Production

```bash
npm run build
```

## Pages
- `/` — Home (hero, features, AI section, community, screenshots, testimonials, FAQ)
- `/about` — About Us (story, team, timeline, values)
- `/blog` — Blog (articles, featured post, newsletter)
- `/contact` — Contact (form, response stats)
- `/help` — Help Center (categories, FAQ)
- `/press` — Press Kit (brand assets, facts, coverage)
- `/privacy` — Privacy Policy
- `/terms` — Terms of Service
- `/cookies` — Cookie Policy

## Tech Stack
- React 18
- React Router v6
- Google Fonts (Sora + DM Sans)
- CSS Modules + Global CSS Variables
- IntersectionObserver for scroll animations
